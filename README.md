# Smart Campus Lost & Found Management System

**Course:** BCA I Semester  
**Session:** 2026–2027  
**Programming Language:** C++

## 1. Project Objective

To develop a system where students can report lost items, submit found items, search for belongings, and match records automatically.

## 2. Project Description

The Smart Campus Lost & Found Management System is a C++ console-based application designed to help students manage lost and found items within the college campus. It allows users to report items, search records, find possible matches, and maintain records using file handling.

## 3. Modules

1. Student Login
2. Report Lost Item
3. Report Found Item
4. Search Item
5. Auto Match Lost & Found
6. View All Records
7. Delete Record
8. Item Statistics
9. Export Report
10. Exit

## 8. File Handling

The application uses text files to store records permanently.

- `lost_found_records.txt` – Stores lost and found item records.
- `lost_found_report.txt` – Stores exported reports.
